# Diagnosing a drop before spending more

A falling add-to-cart or conversion rate is usually a change in who is visiting, not a broken page. Check in this order.

1. **Trend by week.** Sessions, sessions with a cart add, sessions reaching checkout, completed checkouts. Find the week it changed.
2. **Split before and after** by device, landing page, traffic source and country.
3. **Remove junk.** Countries or sources with many sessions and zero carts are bots. Recompute the rate without them.
4. **Compare the same page across periods.** If each page converts the same or better, the mix changed: the high-converting traffic (often ads to a deal page) went away.
5. **Walk the site on a phone.** Product page, each option, add to cart, cart, checkout. Read the cart contents after each tap. Look at the browser console for errors.
6. **Only then fix pages.** Common finds: main button below the first phone screen behind a fixed nav bar, purchase options placed under the button, missing cart images, option combinations that add the wrong item.

Report the cause with the numbers for both periods, and say what you did not check.
